Scheduler

Canvas assignments lined up against your block schedule.

1. Connect Canvas

In Canvas go to Calendar → Calendar Feed and copy the link. It looks like https://yourschool.instructure.com/feeds/calendars/user_XXXX.ics. The code in the URL is what lets this page read your assignments. It is saved only in this browser.

Feed won't load? Upload or paste the .ics file instead

Open the feed URL in a new tab, save the file, then choose it here.

2. Connect your block schedule

In Google Calendar open Settings → your schedule calendar → Integrate calendar and copy the Secret address in iCal format. Events named like Block 1 … Block 8 are picked up as blocks.

Upload the .ics instead

Which class is which block?

Pick the Canvas course for each block. Anything else on the calendar (lunch, assembly…) still shows on the day.
